# ComuniApp

Este projeto foi desenvolvido para a disciplina de QTS e criado completamente com o auxílio do Codex.

## Metodologia

O desenvolvimento seguiu uma metodologia simples e incremental:

1. planejamento das páginas e das funcionalidades principais;
2. geração da estrutura e do código com o Codex;
3. revisão e ajuste dos componentes e das regras do sistema;
4. realização de testes básicos e correção dos problemas encontrados.

## Tecnologias utilizadas

- **JavaScript:** linguagem principal do projeto;
- **Next.js:** framework utilizado para criar as páginas, rotas e funcionalidades do servidor;
- **React:** biblioteca usada na construção dos componentes da interface;
- **Tailwind CSS:** framework responsável pela estilização e pelo layout responsivo;
- **Neon Postgres:** banco de dados utilizado para armazenar as informações;
- **Leaflet e OpenStreetMap:** tecnologias usadas na exibição do mapa;
- **Zod:** biblioteca utilizada para validar os dados enviados ao sistema.

## Funcionalidades

O site permite registrar e consultar ocorrências, visualizar informações em um mapa, acessar serviços comunitários e administrar os dados por meio de um painel restrito.

## Objetivo

O site possui finalidade exclusivamente acadêmica: obter nota na disciplina de QTS e apoiar os estudos sobre desenvolvimento web, principalmente com Next.js e Tailwind CSS. O projeto foi desenvolvido completamente com o auxílio do Codex e não possui finalidade comercial.
